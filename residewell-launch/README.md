## COO + Head of Sales Review (read this)

### What was too vague (now fixed)
| Issue | Fix |
|-------|-----|
| 35 CRM columns, no priority | `crm/week-1-crm-setup.md` — hide columns, 3 filter views |
| 8-criteria scoring slowed research | Quick Score (3 questions, 3 min) added to scorecard |
| Emails generic without examples | Gold standard example + mandatory Personalization Hook |
| No path from reply → calendar | `sales/discovery-call-booking.md` |
| Dashboard tracked too many metrics | **Discovery calls booked** is primary scoreboard |
| Instructor goal competed with sales | Gated: 5 messages only after 10 property emails |

### What was missing (now added)
- Week 1 playbook (one file for the week)
- CRM setup guide with Google Sheets filters
- Contact verification gate before outreach
- Personalization Hook column in CRM
- Discovery call booking templates + SLA
- Daily quotas in dashboard and schedule

### What was overbuilt (deprioritized — do not use week 1)
| File / area | When to use |
|-------------|-------------|
| `proposal/proposal-template.md` | After discovery call, if one-pager isn't enough |
| `proposal/annual-pricing-ladder.md` | After pilot success — never in cold outreach |
| `ai-workflows/*` | Optional accelerator after 10 properties researched |
| `website/landing-page-copy.md` | Duplicate of HTML — update HTML once, move on |
| `operations/client-onboarding-checklist.md` | After deposit received |
| Full 8-criteria Fit Score | After first 15 properties |
| 20 instructor outreaches | After 10 property emails; max 5 week 1 |

### Use first this week (in order)
1. `crm/week-1-crm-setup.md` — set up pipeline (Monday)
2. `crm/property-research-scorecard.md` — Quick Score only
