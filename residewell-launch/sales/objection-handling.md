# Objection Handling

> **Goal:** Keep the conversation moving toward a **15-minute discovery call** or **8-week pilot** — not a debate.

Use on calls, email replies, and discovery calls. **Acknowledge → Reframe → Question → Close.**

---

## Quick reference

| Objection                                                                      | Your move                          | Close with                 |
| ------------------------------------------------------------------------------ | ---------------------------------- | -------------------------- |
| [We already do events](#we-already-do-resident-events)                         | Complement — weekly wellness layer | 8-week pilot to test split |
| [No budget](#we-do-not-have-budget)                                            | $4,000 pilot vs. annual            | Prove value first          |
| [Residents won't attend](#residents-may-not-attend)                            | Registration + reporting           | 8 weeks to measure         |

## Response framework

Every objection uses the same four steps:

| Step            | What to do                                     |
| --------------- | ---------------------------------------------- |
| **Acknowledge** | Validate — never argue                         |
| **Reframe**     | Resident experience / amenity activation angle |
| **Question**    | One qualifying question                        |
| **Close**       | Discovery call or pilot — specific ask         |

---

## We already do resident events

| Step            | Script                                                                                                                                          |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Acknowledge** | "That's great — resident experience is clearly a priority."                                                                                     |
| **Reframe**     | "Teams run strong seasonal events, but weekly wellness programming is harder — instructor coordination, scheduling, follow-through every week." |
| **Question**    | "Is the challenge consistency, or team bandwidth?"                                                                                              |
| **Close**       | "ResideWell handles the weekly layer so you keep doing events well. Worth an 8-week pilot to test that split?"                                  |

---

## We do not have budget

| Step            | Script                                                                                                           |
| --------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Acknowledge** | "I hear that — budget is tight everywhere."                                                                      |
| **Reframe**     | "That's why we lead with an 8-week pilot at $4,000 — low-risk test, often less than one catered resident event." |
| **Question**    | "Timing until next fiscal year, or programming not prioritized at all?"                                          |
| **Close**       | "If timing — I'll follow up for your budget cycle. If proof — the pilot is built for that. Which fits?"          |

---

## Residents may not attend

| Step            | Script                                                                                                                |
| --------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Acknowledge** | "Fair concern — wrong model fails for that reason."                                                                   |
| **Reframe**     | "We use class variety, consistent schedule, registration + reminders, and weekly reporting — so you're not guessing." |
| **Question**    | "Have residents asked for yoga, Pilates, or strength specifically?"                                                   |
| **Close**       | "Eight weeks measures real attendance before any bigger commitment. Does that de-risk it enough?"                     |

---

## We already have a gym

| Step            | Script                                                                                                                                   |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Acknowledge** | "Your fitness center is clearly an asset."                                                                                               |
| **Reframe**     | "We're not a gym replacement — we're amenity activation. Live classes in studio, rooftop, or lounge create community a treadmill can't." |
| **Question**    | "Which spaces are quieter than the gym — studio, courtyard, lounge?"                                                                     |
| **Close**       | "We use existing spaces only. Worth 15 minutes to see if activation fits [Property Name]?"                                               |

---

## We need corporate approval

| Step            | Script                                                                                                                |
| --------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Acknowledge** | "Makes sense — many partners are part of larger management companies."                                                |
| **Reframe**     | "We'll arm you with a one-page pilot overview and scope. Frame as retention and amenity utilization — not 'fitness.'" |
| **Question**    | "Who signs off — regional, VP ops, or marketing?"                                                                     |
| **Close**       | "Should I join a brief call with regional, or do you champion internally first?"                                      |

---

## Send me information

| Step            | Action                                                                                  |
| --------------- | --------------------------------------------------------------------------------------- |
| **Acknowledge** | "Absolutely — sending today."                                                           |
| **Do not**      | End the conversation with PDF only                                                      |
| **Action 1**    | Send one-pager within 2 hours                                                           |
| **Action 2**    | 3 bullets tailored to their property in email body                                      |
| **Action 3**    | Propose 2 call times + calendar link in same email                                      |
| **Close**       | "Overview attached. Worth 15 minutes [date] or [date] to walk through fit for [space]?" |

---

## We are too busy right now

| Step            | Script                                                                                             |
| --------------- | -------------------------------------------------------------------------------------------------- |
| **Acknowledge** | "Completely understand — stretched teams are why we exist."                                        |
| **Reframe**     | "We don't add to your plate. Approve schedule, share a link — under an hour a week for your team." |
| **Question**    | "Busy = check back in 30 days, or programming not a priority?"                                     |
| **Close**       | "If timing — I'll follow up [month]. If priority — I'll step back. Which do you prefer?"           |

---

## We tried fitness classes before and they did not work

| Step            | Script                                                                                                     |
| --------------- | ---------------------------------------------------------------------------------------------------------- |
| **Acknowledge** | "Helpful to know — unfortunately common."                                                                  |
| **Reframe**     | "Usually failed on: inconsistent schedule, wrong instructor fit, or no one owned promotion/registration."  |
| **Question**    | "What went wrong — attendance, instructor quality, or team having to manage it?"                           |
| **Close**       | "Eight-week pilot tests whether a managed model works differently. Open to a short call to compare notes?" |

## Principles

| #   | Rule                                               |
