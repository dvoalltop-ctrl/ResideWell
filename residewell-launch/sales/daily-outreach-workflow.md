# Daily Outreach Workflow

> **One page. Same routine every weekday. Output: discovery calls booked.**

Total time: **45–60 minutes** (morning block) + optional evening call slot.

---

## The daily loop (every weekday)

### 1. Replies first (10 min)

- Open inbox + LinkedIn → answer every prospect reply using `discovery-call-booking.md`
- Any "yes" → calendar invite within 15 minutes
- CRM: update Status on every reply

### 2. Follow-ups due (10 min)

- Open CRM view **TODAY — Follow-Ups**
- Send the next email in sequence (Email 2–5) or LinkedIn follow-up
- CRM: Last Contact → today, Next Follow-Up → +4 business days

### 3. New outreach — 3 Email 1s (15 min)

- Open CRM view **READY TO EMAIL** (Contact Verified = Yes, sorted by Fit Score)
- Personalize with the row's **Outreach Angle** — one specific sentence
- Send 3 → Status → Outreach Sent

### 4. Feed the pipeline (15 min)

- Research 2–3 new properties (`crm/property-research-scorecard.md` — public data only)
- OR verify 2–3 contacts on LinkedIn for already-researched rows
- Alternate: research-heavy Mon/Wed, contact-verification Tue/Thu

### 5. Channel of the day (5–10 min)

| Day | Extra channel                                             |
| --- | --------------------------------------------------------- |
| Mon | — (research focus)                                        |
| Tue | LinkedIn: 3 connection requests                           |
| Wed | LinkedIn: 2 follow-up messages                            |
| Thu | Phone: 2 calls to non-responders (`phone-call-script.md`) |
| Fri | Weekly dashboard + CRM audit                              |

---

## Evening slot (Tue–Thu, 7:00–7:30 PM)

Reserved for discovery calls. If none booked: send proposal follow-ups or prep tomorrow's 3 targets. Never fill it with website tweaks.

---

## Daily minimums (non-negotiable)

| Activity                  | Minimum          |
| ------------------------- | ---------------- |
| Prospect replies answered | All, within 4 hr |
| Email 1s sent             | 3                |
| Follow-ups due            | All              |
| CRM rows updated          | Every touch      |

**Weekly result if you hold the line:** 15 Email 1s, 10 LinkedIn touches, 5 calls → ~3 replies → **2 discovery calls booked**.

---

## If you only have 20 minutes today

1. Answer replies (can't lose a hot lead)
2. Send follow-ups due
3. Send 1 Email 1

Skip research. Pipeline feeding can wait a day; a cold reply cannot.
