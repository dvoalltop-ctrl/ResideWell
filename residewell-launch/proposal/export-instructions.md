# Proposal Export Instructions (Markdown → PDF)

> **Goal:** `ResideWell-8-Week-Pilot.pdf` in your hands, ready to attach within 2 hours of any discovery call.

**MCP status:** No Google Docs/Drive MCP tool is connected in this environment, so use the manual steps below (10 minutes). If you later connect a Drive MCP server (see `../.cursor/mcp/google-drive-setup.example.md`), the agent can automate steps 2–5.

---

## Manual export via Google Docs (recommended)

1. Open `proposal/8-week-pilot-one-pager.md` in Cursor → Ctrl+A, Ctrl+C.
2. Go to [docs.google.com](https://docs.google.com) → Blank document.
3. **Paste with formatting:** Ctrl+V. Tables and headings carry over; tidy anything that wrapped oddly.
4. Customize the `[brackets]`: property name, unit count, spaces, schedule, kickoff date, your phone.
5. Set the look (2 min): Title → bold, 18pt · body → 10.5–11pt · margins → File → Page setup → 0.75" all sides. Aim for **one page** (two max).
6. **File → Download → PDF Document (.pdf)** → save as `ResideWell-8-Week-Pilot-[PropertyName].pdf`.

**Per-property versions:** File → Make a copy of your master Doc, then customize — never re-paste from markdown each time.

## Alternative: Canva (connected in this workspace)

The Canva MCP connection can generate a designed one-pager from the markdown content — useful once the plain-Docs version has closed a pilot and you want extra polish. Ask the agent: _"Create a Canva one-pager from proposal/8-week-pilot-one-pager.md for [Property Name]."_ Review before sending; export as PDF from Canva.

**Don't design before you sell.** The Docs version is enough for the first pilot.

---

## Alternative: print to PDF from Cursor's preview

1. Right-click the `.md` file → open Markdown preview.
2. If your setup supports it, print the preview → "Save as PDF."
3. Check the result — tables sometimes clip; Google Docs is more reliable.
