# Instructor Recruiting Workflow

> **Who owns this?** Founder.
> **When does it happen?** Gate: after **10 property outreach emails** are sent. Volume scales only after a verbal pilot yes.
> **What tools/files are needed?** Google Form (from `instructor-recruiting-form-questions.md`), `instructor-outreach-messages.md`, `instructor-screening-scorecard.md`, `instructor-standards.md`.
> **What does "done" mean?** 2–3 screened instructors per format (yoga, Pilates, strength) with insurance confirmed, rates agreed in writing, and availability locked for 8 consecutive weeks.
> **What can go wrong?** No-shows to screens, rates above budget, insurance gaps, availability that doesn't match property schedules.
> **What is the backup plan?** Keep a bench of 2 per format; every assigned instructor names a sub; if a format has no bench, swap the pilot class format rather than delay launch.

---

## Workflow stages

| Stage           | Trigger                  | Action                                                      | Done when                            |
| --------------- | ------------------------ | ----------------------------------------------------------- | ------------------------------------ |
| 1. Form live    | 10th property email sent | Build Google Form (20 min)                                  | Link tested                          |
| 2. Outreach     | Form live                | Send **5 messages** (Instagram/email/LinkedIn)              | 5 sent, logged                       |
| 3. Applications | Replies arrive           | Send form link same day                                     | Responses in sheet                   |
| 4. Quick screen | Application received     | 5-question pass/fail (scorecard)                            | Pass → video call                    |
| 5. Video screen | Quick screen passed      | 15-min call, confirm rate + availability                    | Scored 8 criteria                    |
| 6. Bench        | Verbal pilot yes         | Confirm 2–3 per needed format                               | Insurance on file                    |
| 7. Assign       | Deposit received         | Assign + brief with `instructor-standards.md` + space guide | Written confirmation for all 8 weeks |

---

## Pay (aligned to unit economics)

| Item                                | Rate                                            |
| ----------------------------------- | ----------------------------------------------- |
| Instructor cost per class           | **$65–$85**                                     |
| Pilot instructor budget (8 classes) | $520–$680                                       |
| Pilot price                         | $4,000 → gross margin well above the 45% target |

Quote the range honestly in outreach; confirm the exact rate on the video screen. Do not exceed $85/class during pilots without checking margin.

---

## Weekly cadence (while selling)

| Sales stage               | Instructor effort                                    |
| ------------------------- | ---------------------------------------------------- |
| < 10 emails sent          | Zero                                                 |
| 10+ emails sent           | 5 outreach messages, form live                       |
| Discovery calls happening | Screen applicants as they arrive (Thu evening slot)  |
| Verbal pilot yes          | Lock the bench for that property's format + schedule |
| Deposit received          | Assign, brief, confirm all 8 weeks                   |

**Never let instructor recruiting displace daily outreach** (`../sales/daily-outreach-workflow.md`). Delivery risk starts only after a sale exists.
