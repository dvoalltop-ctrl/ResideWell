# Instructor Screening Scorecard

**Week 1:** Use **Quick Screen** (4 questions) below. Full 8-criteria score only before assigning to a paid pilot.

**Target before kickoff:** 2 yoga + 1 Pilates + 1 strength — all Quick Screen pass + insurance on file.

---

## Quick Screen (5 min — use week 1)

| #   | Question                                                 | Pass | Fail                      |
| --- | -------------------------------------------------------- | ---- | ------------------------- |
| 1   | Certified + insured (or will obtain before first class)? | Yes  | No → decline              |
| 2   | Available for same day/time for 8 consecutive weeks?     | Yes  | No → backup only          |
| 3   | Taught non-studio or mixed-level before?                 | Yes  | No experience → interview |
| 4   | Rate ≤ $125/class for standard formats?                  | Yes  | No → negotiate or pass    |
| 5   | Responsive communication (replied within 24 hr)?         | Yes  | No → pass                 |

**4–5 pass** → 15-min video call. **3 pass** → backup roster. **<3** → decline politely.

## Full Score (before pilot assignment)

### 1. Certification & Experience (1–5)

| Score | Criteria                                                                        |
| ----- | ------------------------------------------------------------------------------- |
| 5     | Recognized cert (RYT-200+, Pilates certified, NASM/ACE CPT) + 3+ years teaching |
| 4     | Valid cert + 2–3 years                                                          |
| 3     | Cert in progress or 1–2 years with strong references                            |
| 2     | Teaching without formal cert                                                    |
| 1     | No cert, minimal experience                                                     |

---

### 2. Insurance (1–5)

| Score | Criteria                                            |
| ----- | --------------------------------------------------- |
| 5     | Active liability insurance, can provide certificate |
| 3     | Willing to obtain before first class                |
| 1     | Unwilling or unable                                 |

_Non-negotiable for assignment: must have insurance before teaching._

---

### 3. Availability Match (1–5)

| Score | Criteria                                                 |
| ----- | -------------------------------------------------------- |
| 5     | Available on exact days/times needed for active property |
| 4     | Available on needed days, minor time adjustment possible |
| 3     | Partial overlap — could work for some slots              |
| 2     | Limited availability                                     |
| 1     | No overlap with current needs                            |

---

### 4. Reliability Signals (1–5)

| Score | Criteria                                                                         |
| ----- | -------------------------------------------------------------------------------- |
| 5     | Arrives 30+ min early, clear sub plan, professional communication in application |
| 4     | Arrives 15–30 min early, responsive                                              |
| 3     | Average — no red flags                                                           |
| 2     | Vague on punctuality or communication                                            |
| 1     | Red flags: late history, no sub plan, poor responsiveness                        |

---

### 5. Resident / Mixed-Level Fit (1–5)

| Score | Criteria                                                                                   |
| ----- | ------------------------------------------------------------------------------------------ |
| 5     | Experience in apartments, corporate, or community settings; strong answer on modifications |
| 4     | Some non-studio experience; thoughtful answers                                             |
| 3     | Studio only but demonstrates adaptability in interview                                     |
| 2     | Only teaches advanced practitioners                                                        |
| 1     | Dismissive of beginners or low attendance                                                  |

---

### 6. Professionalism & Energy (1–5)

| Score | Criteria                                                             |
| ----- | -------------------------------------------------------------------- |
| 5     | Warm, professional, resident-friendly energy; punctual on video call |
| 4     | Professional, good fit for luxury environment                        |
| 3     | Acceptable                                                           |
| 2     | Too casual, negative about past employers/studios                    |
| 1     | Unprofessional appearance, communication, or attitude                |

---

### 7. Rate Alignment (1–5)

| Score | Criteria                                                |
| ----- | ------------------------------------------------------- |
| 5     | Rate within budget ($75–$125/class depending on format) |
| 4     | Slightly above but negotiable                           |
| 3     | Above budget — possible for premium formats only        |
| 2     | Significantly above budget                              |
| 1     | Rate unrealistic for market                             |

**Budget guide (pilot stage):**

- Yoga / Pilates: $75–$100/class
- Strength / HIIT: $85–$125/class
- Premium / specialty: $100–$150/class

---

### 8. Logistics (1–5)

| Score | Criteria                                                    |
| ----- | ----------------------------------------------------------- |
| 5     | Own music, mats, travels within 30 min of target properties |
| 4     | Own music, travels within 45 min                            |
| 3     | Needs property music setup, otherwise fine                  |
| 2     | Travel or equipment gaps                                    |
| 1     | Cannot solve logistics                                      |

---

## Score Calculation

```
Average Score = Sum of 8 criteria ÷ 8
```

| Average   | Action                                  |
| --------- | --------------------------------------- |
| 4.0+      | Advance to interview → trial assignment |
| 3.5–3.9   | Interview — hold for backup roster      |
| Below 3.5 | Decline politely                        |

---

## Video Interview Questions (15 min)

1. Walk me through a typical class you teach — format, warmup, peak, cooldown.
2. How do you modify for a resident who's never done [yoga/Pilates/strength]?
3. Tell me about a time you had low attendance. What did you do?
4. How early do you arrive? What's your setup process?
5. What happens if you're sick or stuck in traffic?
6. Have you taught in non-studio environments? How was it different?
7. What rate do you expect per class? Are you available for [specific day/time]?
8. Questions for us?

---

## Red Flags (auto-decline)

- [ ] No certification and unwilling to obtain
- [ ] No insurance and unwilling to obtain
- [ ] Speaks negatively about residents or "amateurs"
- [ ] Unreliable communication during screening (late to call, no reply)
- [ ] Rate 2x+ above budget with no flexibility
- [ ] Cannot commit to 8-week minimum schedule
- [ ] Uncomfortable with photography/marketing at property

---

## Approval Checklist (before first assignment)

- [ ] Average score 4.0+ (or 3.5+ with strong interview)
- [ ] Insurance certificate on file
- [ ] Rate confirmed in writing
- [ ] Availability confirmed for full pilot duration
- [ ] Read and agreed to `instructor-standards.md`
- [ ] Emergency contact and sub plan documented
