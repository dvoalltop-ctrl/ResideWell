# Pilot Launch Checklist

**Property:** _______________  
**First class date:** _______________  
**Launch week:** _______________

Final pre-flight check. Complete 48 hours before first class.

---

## Agreements & Money

- [ ] Signed pilot agreement on file
- [ ] Deposit / first payment received
- [ ] Vendor setup complete (if required)
- [ ] COI delivered to property (if required)

---

## Schedule & Spaces

- [ ] 8-week schedule confirmed in writing with property
- [ ] Each class has: date, time, format, instructor, space
- [ ] Property walkthrough complete
- [ ] Weather backup plan documented (outdoor classes)
- [ ] Property contact confirmed for first class day

---

## Instructors

- [ ] All week 1–2 instructors confirmed
- [ ] Instructors have: access instructions, space photos, standards doc
- [ ] Backup instructor on standby for week 1
- [ ] Instructor insurance verified
- [ ] Instructor rates confirmed

---

## Residents

- [ ] Registration link live and tested
- [ ] Property sent resident email announcement
- [ ] Property posted on portal / social
- [ ] Lobby signage placed (if applicable)
- [ ] Pre-registrations for week 1: _____ (goal: 5+ per class)

---

## Operations

- [ ] Attendance tracker ready (`class-attendance-tracker.csv`)
- [ ] Resident feedback method decided
- [ ] ResideWell on-call for first class: Y / N
- [ ] Post-class debrief scheduled with instructor
- [ ] Week 4 mid-pilot review on calendar

---

## Promo Kit Delivered to Property

- [ ] Email copy for residents (approved)
- [ ] Social media posts (2–3, approved)
- [ ] Lobby flyer PDF (if applicable)
- [ ] Registration link + QR code
- [ ] Class schedule one-pager

---

## Day-Before First Class

- [ ] Confirm instructor is ready
- [ ] Confirm property contact is aware
- [ ] Check weather (outdoor)
- [ ] Send property contact: "See you tomorrow — [time], [space], [instructor name]"

---

## Day-of First Class

- [ ] Instructor arrived on time (confirm via text)
- [ ] Setup complete 15 min before start
- [ ] Attendance recorded
- [ ] Photos taken (with resident permission / property approval)
- [ ] Issues logged
- [ ] Thank-you text to property contact after class

---

## Week 1 Complete

- [ ] Attendance data entered in tracker
- [ ] Brief report sent to property: "Week 1 — [X] residents, [highlights], week 2 confirmed"
- [ ] Instructor debrief complete
- [ ] Adjust week 2 promotion if attendance was low

---

## If Attendance Is Low Week 1 (< 5)

1. Ask property to resend email with direct link
2. Post reminder on social / portal
3. Consider time/format adjustment for week 3 (not week 2 — give it 2 weeks)
4. Offer property a "bring a neighbor" prompt
5. Do NOT panic — luxury properties often ramp slowly
