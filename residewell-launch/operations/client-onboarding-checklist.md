# Client Onboarding Checklist

**Property:** _______________  
**Kickoff date:** _______________  
**Point of contact:** _______________  
**Pilot tier:** Lean / Standard / Premium — $_______________

---

## Phase 1: Contract & Payment (Week -2)

- [ ] Pilot agreement signed by property / management company
- [ ] Invoice sent
- [ ] Payment received (50% upfront per terms)
- [ ] W-9 or vendor setup complete (if required by management company)
- [ ] Certificate of insurance sent (obtain GL policy before first class if needed)
- [ ] Add property to internal tracking sheet

---

## Phase 2: Kickoff Call (Week -2)

**Attendees:** Community manager, ResideWell founder

- [ ] Confirm class schedule (days, times, formats)
- [ ] Confirm spaces for each class type
- [ ] Confirm building access process (keys, fob, sign-in)
- [ ] Confirm point of contact for day-of issues
- [ ] Confirm promotion channels (email, portal, social, lobby)
- [ ] Confirm resident registration process
- [ ] Schedule property walkthrough
- [ ] Send recap email within 24 hours

---

## Phase 3: Property Walkthrough (Week -1)

Use `property-walkthrough-checklist.md`

- [ ] Walk all class spaces
- [ ] Photo/video for instructor briefing
- [ ] Confirm AV/music setup
- [ ] Confirm restroom and water access for residents
- [ ] Confirm storage for mats/equipment if applicable
- [ ] Confirm parking for instructors
- [ ] Exchange emergency contacts

---

## Phase 4: Instructor Assignment (Week -1)

- [ ] Instructors assigned and confirmed for full 8 weeks
- [ ] Rates confirmed in writing
- [ ] Insurance certificates on file
- [ ] Instructors received property briefing (space photos, access, standards)
- [ ] Backup instructor identified for each format

---

## Phase 5: Resident Registration (Week -1)

- [ ] Registration link created (Google Form, Eventbrite, or simple tool)
- [ ] Property approved registration copy
- [ ] Property sends resident announcement email
- [ ] Property posts on resident portal / social
- [ ] Lobby flyer placed (if applicable)
- [ ] First-week registration count: _____

---

## Phase 6: Launch (Week 1)

- [ ] ResideWell on-site or on-call for first class
- [ ] Attendance tracked
- [ ] Resident feedback collected (informal)
- [ ] Debrief with instructor within 24 hours
- [ ] Thank property contact — confirm week 2 is on track

---

## Phase 7: Ongoing (Weeks 2–7)

- [ ] Weekly attendance submitted every class day
- [ ] Weekly check-in email to property contact (optional but recommended)
- [ ] Week 4: mid-pilot review call
- [ ] Week 4: second payment invoice (if 50/50 terms)
- [ ] Adjust class mix if attendance data warrants

---

## Phase 8: Closeout (Week 8)

- [ ] Final class completed
- [ ] Final attendance data compiled
- [ ] Resident feedback form sent (see `resident-feedback-form-questions.md`)
- [ ] Final report delivered to property + regional contact
- [ ] Annual program proposal sent within 7 days
- [ ] Conversion call scheduled
- [ ] Request testimonial or case study permission

---

| Document | When |
