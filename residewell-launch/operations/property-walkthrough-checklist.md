# Property Walkthrough Checklist

**Property:** _______________  
**Date:** _______________  
**Attending:** _______________ (ResideWell) + _______________ (Property)

Complete this on-site before the first class. Take photos of every space.

---

## Access & Logistics

- [ ] Building entry process for instructors documented
- [ ] Amenity access: key / fob / sign-in procedure
- [ ] After-hours access rules (if evening classes)
- [ ] Parking: where instructors park (visitor, garage level, street)
- [ ] Loading/unloading equipment — nearest entrance
- [ ] Emergency contact on-site: name + phone
- [ ] ResideWell emergency contact shared with property

---

## Class Space 1: _______________

**Planned format:** _______________  
**Planned schedule:** _______________

- [ ] Room dimensions adequate for expected attendance (8–15)
- [ ] Flooring appropriate (yoga mat, cardio, etc.)
- [ ] Mirrors, if needed
- [ ] Electrical outlets for speaker
- [ ] Lighting controls
- [ ] Temperature / HVAC — can it be adjusted?
- [ ] Storage for mats/equipment
- [ ] Water access for residents nearby
- [ ] Restroom nearby
- [ ] Max capacity per fire code (ask property): _____
- [ ] Noise restrictions (especially if above/below residents)
- [ ] Photos taken: wide angle + outlets + storage

---

## Class Space 2: _______________ (if applicable)

- [ ] Same checklist as Space 1

---

## Outdoor / Rooftop (if applicable)

- [ ] Weather backup plan agreed
- [ ] Wind / sun exposure noted
- [ ] Noise restrictions (time of day)
- [ ] Furniture moveable or fixed
- [ ] Access door locks — who opens?
- [ ] Photos taken

---

## Equipment & AV

- [ ] Property provides: mats / weights / nothing
- [ ] Instructor brings: speaker / mats / all equipment
- [ ] Bluetooth speaker on-site? Y / N
- [ ] TV or screen for virtual hybrid? Y / N
- [ ] WiFi available in class space? Y / N

---

## Resident Experience

- [ ] Signage: where can we post class schedule? (lobby, elevator, gym door)
- [ ] Registration QR code placement agreed
- [ ] Resident email blast — who sends, when?
- [ ] Resident portal post — who posts?
- [ ] Social media — property handle, tagging rules
- [ ] Any resident groups (Facebook, GroupMe) we should know about?

---

## Safety

- [ ] AED location: _______________
- [ ] First aid kit location: _______________
- [ ] Emergency exits from class space identified
- [ ] Incident reporting process: who does property call?
- [ ] Pool rules if class is pool-adjacent

---

## Setup & Breakdown Rules

- [ ] Furniture to move before class: _______________
- [ ] Furniture must be returned after class: Y / N
- [ ] Cleaning supplies available: Y / N
- [ ] Trash disposal: _______________
- [ ] Lights / locks after last class: _______________

---

## Post-Walkthrough

- [ ] Send property contact a recap email with photos and confirmed schedule
- [ ] Brief assigned instructors with space guide (photos + access notes)
- [ ] Add access instructions to internal property file
- [ ] Flag any issues that need resolution before week 1

---
