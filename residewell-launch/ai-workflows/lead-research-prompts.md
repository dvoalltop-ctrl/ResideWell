# Lead Research Prompts

Copy these into Cursor, ChatGPT, or Claude. Replace `[brackets]` with your inputs.

---

## Prompt 1: Research a Target Property

```
You are helping me research a luxury apartment property for B2B sales outreach.

Property name: [Property Name]
City/Submarket: [e.g., Buckhead, Atlanta]
Website (if known): [URL or "find it"]

Research and return ONLY verified or clearly labeled information:

1. PROPERTY BASICS
- Official name, address, website
- Unit count (cite source)
- Property class (A, A-, B+) and why
- Management company
- Ownership company (if public)

2. AMENITIES
- Fitness center, yoga/studio, rooftop, pool, courtyard, resident lounge
- Note which spaces look underused or premium

3. RESIDENT PROGRAMMING SIGNALS
- Evidence of events (website, social, reviews)
- What types of events
- How active (weekly, monthly, seasonal only)

4. REVIEWS
- Google rating (approximate)
- 3 recurring review themes
- Any mentions of amenities, community, or events

5. CONTACT RESEARCH GUIDANCE
- Suggested LinkedIn search strings for community manager
- Suggested LinkedIn search strings for regional manager
- Do NOT invent names or emails — say "not found" if unknown

6. FIT FOR RESIDEWELL
- Score 1-5 on: unit count, luxury positioning, amenity quality, events evidence, location, likelihood to pay
- One-sentence likely pain point
- Priority: High / Medium / Low

Label anything uncertain as ASSUMPTION. Do not fabricate contact information.
```

## Prompt 2: Batch Research Submarket

```
I'm building a CRM of 50 Class A luxury apartment properties in metro Atlanta.

Submarket: [Buckhead / Midtown / Sandy Springs / Alpharetta / etc.]
Target count: [e.g., 8 properties]

List [count] Class A or luxury-oriented apartment communities in this submarket.

For each property provide:
- Property name
- Approximate unit count
- Website URL
- Management company (if known)
- Notable amenities
- Why it's a fit for resident wellness programming

Do NOT invent contact names or emails.
Mark unverified data as UNVERIFIED.
Prioritize properties with 200+ units and strong amenity packages.
```

## Prompt 3: Find Management Company Portfolio

```
Management company: [e.g., Greystar, Lincoln Property Company]
Market: Atlanta metro

List luxury/Class A properties this company manages in:
Buckhead, Midtown, Sandy Springs, Alpharetta, Brookhaven, Johns Creek, Duluth, Suwanee, North Atlanta.

For each:
- Property name
- Submarket
- Approximate units
- Website

This is for portfolio expansion sales — I want properties where one regional relationship could lead to multiple pilots.

Do not invent contacts. Flag data as UNVERIFIED if not certain.
```

## Prompt 4: Review Theme Extraction

```
I'm researching [Property Name] in [City] for B2B outreach.

Based on publicly available Google reviews (or general reputation if you cannot access live data), identify:

1. Approximate star rating
2. Top 5 positive themes (with example paraphrased quotes)
3. Top 3 negative or neutral themes
4. Any mentions of: amenities, fitness, events, community, staff
5. One sentence on how ResideWell (resident wellness programming for luxury apartments) could address a gap

Do not fabricate specific review text. Label assumptions clearly.
```

---

## Prompt 5: Competitive / Alternative Landscape

```
In the Atlanta luxury multifamily market, how do Class A properties typically handle resident events and wellness programming?

Cover:
- In-house community manager events
- Third-party event vendors
- Gym/fitness center only (no programming)
- Digital fitness apps (ClassPass, etc.)
- National resident experience platforms

What gaps does a turnkey operator like ResideWell fill?

Keep it practical for a founder preparing discovery call talking points.
```

---

## Usage Tips

1. Run Prompt 1 for every High-priority property before outreach.
2. Paste results into CRM **Notes** field — don't trust AI for emails without verification.
3. Always verify unit count and management company on the property website.
4. Never paste AI-generated contacts into CRM without LinkedIn verification.
