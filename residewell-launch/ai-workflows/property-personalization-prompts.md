# Property Personalization Prompts

Use after research, before sending outreach or after discovery calls.

---

## Prompt 1: Personalize Outreach Email

```
Write a personalized B2B outreach email for ResideWell.

CONTEXT:
- ResideWell helps luxury apartment communities activate amenity spaces with live wellness programming (classes, registration, attendance, reporting) without adding work to the property team.
- Offer: 8-week pilot, 2 classes/week, $4,000 all-inclusive.

PROPERTY:
- Name: [Property Name]
- Submarket: [Submarket]
- Contact name: [First Name] or "there" if unknown
- Unit count: [X]
- Amenities: [list]
- Research notes: [paste from CRM]
- Likely pain point: [your hypothesis]

REQUIREMENTS:
- Tone: professional, premium, B2B — NOT a gym sales pitch
- 120-180 words max
- One specific observation about THEIR property (amenity, review theme, or positioning)
- Soft CTA: 15-minute call
- No fake familiarity — don't say "I loved visiting" if I haven't
- Subject line included

Write Email 1 (soft intro) only.
```

## Prompt 2: Personalize LinkedIn Connection Note

```
Write a LinkedIn connection request (max 300 characters) for:

My name: [Your Name]
My company: ResideWell — resident wellness & amenity activation for luxury multifamily
Their name: [First Name]
Their role: [Community Manager / Regional Manager]
Property/company: [Property Name / Management Co.]
One specific detail: [amenity, portfolio, post they wrote, etc.]

Professional, not salesy. No pitch in the connection request.
```

## Prompt 3: Summarize Discovery Call

```
Summarize this discovery call for my CRM and follow-up email.

PROPERTY: [Property Name]
CONTACT: [Name, title]
DATE: [Date]

RAW NOTES:
[paste your messy notes]

Return:

1. CRM SUMMARY (3-5 bullets for Notes field)
2. KEY QUOTES (2-3 things they said in their words)
3. PAIN POINTS identified
4. DECISION PROCESS (who else involved, budget, timeline)
5. QUALIFICATION: Green / Yellow / Red + why
6. RECOMMENDED NEXT STEP
7. DRAFT thank-you email (short, with pilot mention, attach one-pager)
8. CUSTOM PROPOSAL ANGLES (3 bullets to emphasize in proposal)
```

Write follow-up email #2 for a property manager who hasn't replied.

## Prompt 5: Draft Phone Call Talking Points

```
I'm calling [First Name], [title] at [Property Name] in [Submarket].

Context from research:
[paste CRM notes]

Create a phone cheat sheet:
- Opening line (15 sec)
- Reason for calling (15 sec)
- 3 qualifying questions
- How to ask for 15-min call
- Voicemail script (under 30 sec)
- Likely objection + response (1)

Keep it scannable — bullet format only.
```

---

## Usage Tips

1. Always read AI output aloud — if it sounds generic, add one more property-specific detail.
2. Never send without verifying the contact name and property details.
3. Save your best personalized emails in CRM Notes as templates for similar properties.
