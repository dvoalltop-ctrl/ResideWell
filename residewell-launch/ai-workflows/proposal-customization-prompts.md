# Proposal Customization Prompts

Use after discovery calls to draft custom proposals quickly.

---

## Prompt 1: Custom Proposal Draft

```
Draft a customized ResideWell proposal using our template structure.

CLIENT:
- Property: [Property Name]
- Contact: [Name, title]
- Address: [Address]
- Units: [count]
- Submarket: [submarket]

DISCOVERY CALL NOTES:
[paste notes]

PROGRAM:
- Tier: Standard 8-Week Pilot — $4,000
- Proposed schedule: [days/times]
- Proposed spaces: [spaces]
- Class mix: [yoga, Pilates, strength, etc.]
- Proposed kickoff: [date]

Include:
1. Executive summary (3 sentences)
2. Objectives (3 bullets from THEIR words)
3. Proposed program table
4. What's included
5. Property responsibilities
6. Success metrics with realistic targets for [unit count] property
7. Investment and payment terms (50/50)
8. Timeline with specific dates
9. Next steps

Tone: professional, premium, B2B. Not a gym pitch.
```

---

## Prompt 2: Objectives from Discovery Notes

```
From these discovery call notes, write 3 proposal objectives in the property's language (not ResideWell jargon).

Notes:
[paste]

Format:
1. [Objective — what THEY want to achieve]
2. [Objective]
3. [Objective]

Each objective should be one sentence, measurable where possible.
```

---

## Prompt 3: Class Schedule Recommendation

```
Recommend a class schedule for this property.

Property: [Name]
Units: [count]
Resident profile: [young professionals / families / mixed — from discovery]
Amenities: [fitness center, studio, rooftop, etc.]
Competing time demands: [if known — e.g., lots of WFH residents]

Pilot: 8 weeks, 1 class/week

Recommend:
- 2 class formats
- Days and times
- Which space for each
- Rationale for each choice

Keep it practical for a community manager to approve.
```

---

## Prompt 4: Success Metrics Targets

```
Set realistic pilot success metrics for:

Property: [Name]
Unit count: [X]
Class frequency: 1x/week
Formats: [yoga, Pilates, etc.]

Provide targets for:
- Average attendance per class
- Unique residents participating (total over 8 weeks)
- Repeat attendance rate (% who come 2+ times)
- Registration rate (% of units who register at least once)

Explain your reasoning in 2-3 sentences.
```

---

## Prompt 5: Proposal Email Cover Letter

```
Write a short email to accompany a custom proposal PDF.

Contact: [First Name]
Property: [Property Name]
We discussed: [1-2 specifics from call]
Proposal attached: 8-week pilot at $4,000
Proposed kickoff: [date]

100-130 words. Warm but professional. Propose 2 specific times for a follow-up call.
```

---

## Prompt 6: Annual Conversion Proposal (Post-Pilot)

```
Draft an annual program recommendation after a successful pilot.

Pilot results:
- Average attendance: [X]
- Unique residents: [Y]
- Repeat rate: [Z]%
- Resident feedback highlights: [paste]
- Property contact sentiment: [positive / wants more / budget cautious]

Recommend Essential ($1,250/mo), Standard ($1,800/mo), or Premium ($2,700-3,300/mo) and why.

Include:
- 1-paragraph executive summary
- Recommended tier with specifics
- Pilot credit offer ($2,000 off if signed within 30 days)
- 3-bullet ROI argument for ownership
```

---

## Usage Tips

1. Export AI draft to Google Docs, add property logo space, export PDF.
2. Always include something from the discovery call they said verbatim.
3. Send within 24 hours of discovery call — speed wins deals.
