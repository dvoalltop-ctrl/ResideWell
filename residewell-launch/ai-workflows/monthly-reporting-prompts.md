# Monthly Reporting Prompts

Use for client reports, attendance insights, and follow-up emails.

---

## Prompt 1: Monthly Client Engagement Report

```
Write a monthly resident wellness engagement report for a luxury apartment property.

PROPERTY: [Property Name]
MONTH: [Month Year]
PROGRAM: [Pilot week X of 8 / Essential / Standard / Premium]

DATA:
[paste attendance tracker rows or summary]

Class schedule this month:
[list classes, formats, instructors]

Resident feedback (if any):
[paste]

Property contact: [Name]

Create a 1-page report with:

1. EXECUTIVE SUMMARY (3-4 sentences for community manager to forward to regional)
2. ATTENDANCE HIGHLIGHTS
   - Total classes held
   - Total attendance
   - Average per class
   - Unique residents
   - Repeat attendance rate
3. TOP PERFORMING CLASSES (format + time)
4. RESIDENT FEEDBACK SUMMARY (quotes if provided)
5. OBSERVATIONS & RECOMMENDATIONS (2-3 actionable items)
6. NEXT MONTH PLAN (class schedule adjustments if any)

Tone: professional, data-driven, premium. Suitable for forwarding to ownership.
```

## Prompt 2: Resident Event Ideas

```
Generate 6 resident wellness event ideas for a luxury apartment property.

Property: [Name]
Submarket: [submarket]
Resident profile: [demographic]
Existing amenities: [list]
Current class schedule: [formats and times]
Season: [spring/summer/fall/winter]
Budget level: [included in premium tier / small add-on / low-cost]

For each event:
- Name
- Format (45-90 min)
- Best location on property
- Estimated attendance
- Why residents would care
- Operational complexity (Low / Medium / High)

Avoid gimmicks. Premium, not cheesy. Suitable for Class A multifamily.
```

## Prompt 3: Attendance Data → Insights

```
Analyze this class attendance data and give me actionable insights.

PROPERTY: [Name]
UNIT COUNT: [X]
PROGRAM: [pilot week X / monthly]

ATTENDANCE DATA:
[paste CSV rows or table]

Answer:
1. Which format + time slot performs best? Worst?
2. Is attendance trending up, flat, or down?
3. Estimated % of units reached at least once
4. Repeat attendance pattern — who comes back?
5. Three specific recommendations for next 4 weeks
6. One paragraph summary for property manager (non-technical)

Be direct. Flag if sample size is too small to conclude.
```

## Prompt 4: Week 4 Mid-Pilot Check-In Email

```
Draft a mid-pilot check-in email to the property manager.

Property: [Name]
Contact: [First Name]
Weeks complete: 4 of 8

Attendance summary:
- Classes held: [X]
- Total attendance: [Y]
- Average per class: [Z]
- Best class: [format + time]

Highlights: [any positive feedback or moments]
Concern (if any): [low attendance on specific slot, etc.]
Recommendation: [keep schedule / swap format / increase promotion]

150 words. Collaborative tone. Propose a 15-min call if adjustments needed.
```

## Prompt 5: Week 8 Final Report Narrative

```
Write the narrative sections of a final 8-week pilot report.

Property: [Name]
Units: [X]

FULL PILOT DATA:
[paste attendance + feedback]

Include:
1. Executive summary (property can forward to regional/ownership)
2. Program overview (what we ran)
3. Results vs. success metrics (table format)
4. Resident feedback themes
5. ROI narrative for retention and amenity utilization (qualitative — no fake numbers)
6. Recommendation: annual tier (Essential / Standard / Premium) with rationale
7. Proposed next 90 days if they renew

Professional, consultative. This document wins the annual contract.
```

## Prompt 7: Turnaround Low Attendance

```
Attendance is below target at a luxury apartment pilot.

Property: [Name]
Units: [X]
Week: [X of 8]
Average attendance: [Y] (target was [Z])
Classes: [schedule]
Promotion done so far: [email, portal, social, lobby]

Diagnose likely causes and give a 7-day action plan:
- Property team actions (3 items)
- ResideWell actions (3 items)
- Schedule/format changes to consider
- Message to send residents (short email copy)

Be practical. Pilots often ramp slow — don't overreact in week 2.
```

---

## Usage Tips

1. Paste raw attendance CSV — AI is good at narrative, you verify numbers.
2. Send week 4 and week 8 reports even if attendance is mediocre — honesty builds trust.
3. Save final report PDFs — they're your case studies for the next sale.
