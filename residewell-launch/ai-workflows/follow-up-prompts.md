# Follow-Up Prompts

Copy into Cursor/ChatGPT/Claude. Replace `[brackets]`. Every output should move toward a booked call, a signed pilot, or a clean close-out.

---

## Prompt 1: Follow-up after no reply

```
Write follow-up email #[2/3] for a property manager who hasn't replied.

Property: [Name] — [Submarket]
Contact: [First Name], [title]
Prior touches: [Email 1 on date — angle used]
This email's angle: [amenity activation / renewal support / 8-week pilot]
Specific detail to reference: [space or review theme from CRM]

Rules: under 120 words, professional B2B (amenity activation, not fitness),
one CTA = 15-minute call with 2 time options, include subject line.
ResideWell handles programming, instructors, resident marketing, registration,
attendance tracking, and reporting.
```

---

## Prompt 2: Follow-up after discovery call (no decision yet)

```
Write a follow-up email 3 days after sending a pilot proposal.

Property: [Name]
Contact: [First Name]
Call notes: [2-3 bullets — pain points, spaces discussed, their timeline]
Proposal sent: 8-week pilot, $4,000, [date]
Their hesitation (if known): [budget timing / corporate approval / attendance risk]

Rules: under 110 words, reference one specific thing THEY said, offer to answer
questions async or on a 10-minute call, no discounting, include subject line.
```

---

## Prompt 3: Re-engage a gone-quiet proposal (day 7 and day 14)

```
Write a short re-engagement email for a proposal sent [X] days ago with no response.

Property: [Name] · Contact: [First Name]
Proposal: 8-week pilot, $4,000
Tone: direct but gracious — this is touch [2/3] since the proposal.

Day-7 version: add one new piece of value (resident event idea for their [space],
or a relevant insight about [submarket] communities).
Day-14 version: polite decision ask — "Should I keep [Property Name] on my
calendar for [month], or is this a no for now?" Either answer is fine.
Under 100 words, subject line included.
```

---

## Prompt 4: Nurture check-in (60–90 days)

```
Write a 60-day nurture check-in for a property that said "not now."

Property: [Name] · Contact: [First Name]
Last conversation: [date + one-line summary]
What changed since: [new season / their stated budget cycle / a pilot result I can reference]

Rules: under 90 words, zero pressure, one specific reason it might be timely now,
soft CTA (15 minutes or "reply and I'll send the current one-pager"), subject line.
```

---

## Prompt 5: Post-verbal-yes momentum

```
Write the "next steps" email after a verbal yes on the 8-week pilot.

Property: [Name] · Contact: [First Name]
Agreed on call: [price $4,000, proposed kickoff, spaces, class day/time]

Include: warm one-line open, numbered next steps (agreement, 50% deposit,
kickoff call date options, property to-dos: registration link share + space access),
proposed kickoff date ~2 weeks out, close with excitement but zero fluff.
Under 150 words, subject line included.
```

---

## Prompt 6: Break-up email that leaves the door open

```
Write a final break-up email after [4] unanswered touches.

Property: [Name] · Contact: [First Name]
Rules: 3 sentences max. No guilt. State you'll stop reaching out, leave the
8-week pilot as the standing option, invite them to reply anytime.
P.S. asking who else on their team owns resident events, if anyone.
Subject line included.
```

---

## Usage rules

1. Paste real CRM notes — generic input produces generic email.
2. Read output loud once; cut anything that sounds like a template.
3. Log every send in the CRM: Last Contact, Next Follow-Up, Status.
4. SLAs still apply: replies get answers within 4 hours (`../sales/discovery-call-booking.md`).
