# ResideWell Operations

When creating operations files for ResideWell, build simple repeatable systems.

Every checklist should answer:

1. Who owns this?
2. When does it happen?
3. What tools/files are needed?
4. What does "done" mean?
5. What can go wrong?
6. What is the backup plan?

Prioritize:

- Client onboarding
- Property walkthrough
- Instructor confirmation
- Class setup
- Resident registration
- Attendance tracking
- Feedback collection
- Monthly reporting
- Renewal preparation

Keep processes simple enough for a founder working part-time.

## Reference

Operations files live in `residewell-launch/operations/`. Business priorities and the sales-first decision rule: the `residewell-business-context` skill.
