# ResideWell Pricing & Financials

When creating pricing, financial models, or revenue projections for ResideWell, use conservative assumptions.

## Default assumptions

- Instructor cost per class: $65–$85
- Event facilitator cost: $200–$400
- Event supplies: $100–$300
- Monthly admin/reporting time per property: 2–4 hours
- Target gross margin: 45%+
- Minimum pilot price: $3,500
- Preferred pilot price: $4,000
- Standard annual package: $21,600/year

## Track

- Properties contacted
- Contacts added
- Reply rate
- Discovery calls booked
- Proposals sent
- Pilots closed
- Pilot-to-annual conversion
- Monthly recurring revenue
- Gross margin
- Instructor reliability
- Attendance per class
- Resident satisfaction
