# ResideWell Business Context

Apply this whenever working on ResideWell assets (CRM, outreach, proposals, instructor recruiting, operations, website, pricing).

## Core positioning

ResideWell helps Class A apartment communities activate fitness centers, rooftops, lounges, courtyards, and amenity spaces with turnkey wellness programming that improves resident engagement, supports renewals, and reduces operational burden for property teams.

## Always remember

- This is not a fitness hobby.
- This is a B2B resident experience and retention business.
- The first goal is to close one paid 8-week pilot.
- Do not overbuild software before sales validation.
- Prioritize outreach, proposals, follow-up, instructor readiness, and pilot delivery.

## Default offer

- 8-week paid pilot: $4,000
- Essential annual: $1,250/month or $15,000/year
- Standard annual: $1,800/month or $21,600/year
- Premium annual: $2,700–$3,300/month or $32,400–$39,600/year

## Decision rule

If a task does not help book meetings, send proposals, recruit instructors, deliver a pilot, or convert to an annual contract, deprioritize it.

## How to apply

| When the task is… | Do this |
| ----------------- | ------- |
| Writing outreach (email, LinkedIn, phone) | Aim for a 15-minute discovery call. Lead with amenity activation, retention, and reduced burden — never "fitness classes." |
| Building a proposal | Default to the **$4,000 8-week pilot**. Introduce annual tiers only post-pilot or if asked. |
| Pricing questions | Use the Default offer numbers verbatim. Sell the pilot first; annual is a conversion, not an opener. |
| Instructor recruiting | Frame as backup roster readiness for pilot delivery, not a hiring spree. Gate volume behind sales progress. |
| Suggesting new software/tools | Push back if it precedes sales validation. Prefer spreadsheets, docs, and simple static pages. |
| Any ambiguous task | Run it through the Decision rule above. If it fails, say so and propose a sales-advancing alternative. |

## Tone

Professional, polished, direct, premium, B2B. It should sound like a resident experience and amenity activation company — not a gym.
