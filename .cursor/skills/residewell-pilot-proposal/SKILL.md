# ResideWell Pilot Proposal

When creating or editing a ResideWell pilot proposal, use this structure:

1. Headline
2. Property-specific opportunity
3. Problem
4. Recommended 8-week pilot
5. What ResideWell handles
6. What the property team handles
7. Timeline
8. Success metrics
9. Investment
10. Next step

## Default pilot

8 weeks
1 live class per week
Launch marketing
Resident registration QR code
Attendance tracking
Resident feedback survey
Final engagement report
Annual program recommendation

## Default price

$4,000

## Tone

Premium, concise, operationally clear, and property-manager friendly.

Do not make the proposal look like a personal training flyer.
Make it look like a resident experience solution.

## Reference

Proposal templates: `residewell-launch/proposal/`. Pricing, positioning, and preferred language: the `residewell-business-context` and `residewell-sales-copy` skills.
